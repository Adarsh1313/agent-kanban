Quiet Instrument

Agent Kanban's design system. Almost no colour: neutrals carry the layout, and only agent states and provider logos light up. Calm and precise, closest to Linear. Everything here is live. Hover, click and tab through it. All values come from tokens.css, components from components.css.

Signature: a chat's life on the board

The one moment that matters most. Agent events move a card on their own: it lifts slightly, travels on a strong ease-in-out curve, and the column counts tick. Press Play, or step it by hand with the buttons that appear on the card.

Running: the activity line crossfades as each step starts.

Running card

The card shows what the agent is doing right now, with a thin sweep that says "alive" without a pulsing dot. Show more opens the last few steps with a short stagger. Hovering reveals Stop. Stopping moves the card to Needs you with a Stopped badge and a Resume button. Nothing is lost, so it needs no confirmation.

Sidebar

Linear's structure, made ours: workspace switcher, New chat with its shortcut, then Needs you, Board, Usage and Connect. Folders and Providers collapse. The selected item gets a soft capsule that slides, not a coloured left border. The Needs you count is the only tinted number.

Rules

  • One capsule, sliding over --duration-move with --ease-out.
  • Hover tints the row; it never moves.
  • Provider rows show the logo and a connection dot paired with a tooltip label.
  • Section chevrons rotate; the list opens with a height and opacity reveal.
  • Keyboard: N opens New chat with no animation delay on the trigger.

Usage limits

The top bar shows one chip per provider: its logo, two hairline meters (5-hour on top, weekly below) and the lower of the two numbers. Clicking opens the dropdown, which scales in from the chip. Each provider expands By model where the provider reports per-model limits. Meters turn amber under 25% and red under 5%. The text always says the number too, so colour is never the only signal.

Components

Buttons

One primary button per view. Every button dips to 97% on press. The Stop button swaps its label through a short blur. Icon-only buttons always have a label and a tooltip: the first tooltip waits, the next ones appear instantly.

Badges, state icons and logos

Feedback

Toasts rise from the bottom centre, pause while hovered or while the window is hidden, and leave faster than they arrive.

Motion

The board is used all day, so motion stays functional and quick. Things animate when they appear, travel or change state, never just to decorate. Exits are always faster than entrances. Keyboard-triggered actions open instantly in spirit, so nothing waits on an animation before you can type.

Colour

Swatches read live from the tokens, so they follow light and dark.

Type

Geist for everything. Geist Mono only for file names and commands inside agent activity, never for UI labels. Numbers use tabular figures so meters and counts don't jitter.
