Quiet Instrument

Agent Kanban's design system. Almost no colour: neutrals carry the layout, and only agent states and provider logos light up. Calm and precise, closest to Linear. Everything here is live. Hover, click and tab through it. All values come from tokens.css, components from components.css.

Signature: a chat's life on the board

The one moment that matters most. Agent events move a card on their own: it lifts slightly, travels on a strong ease-in-out curve, and the column counts tick. Press Play, or step it by hand with the buttons that appear on the card.

Running: the activity line crossfades as each step starts.

Running card

The card shows what the agent is doing right now, with a thin sweep that says "alive" without a pulsing dot. Show more opens the last few steps with a short stagger. Hovering reveals Stop. Stopping moves the card to Needs you with a Stopped badge and a Resume button. Nothing is lost, so it needs no confirmation.

Sidebar

Linear's structure with Claude's chat list. Board, Projects and Connections at the top. Providers act as a quick focus: clicking one filters the board and swaps the top-bar usage to just that provider. Pinned and Recent chats list the real chats found in each provider's history, grouped by project, with the same titles the provider uses. Each project row shows which providers have worked on it.

Rules

  • One capsule, sliding over --duration-move with --ease-out.
  • Hover tints the row; it never moves. Row actions (…, +) fade in on hover or focus.
  • A chat row's state shows only when it needs attention: the running ring or a needs-you dot.
  • Three chats per project, then "Show N more".
  • Section chevrons rotate; lists open with a height and opacity reveal.

The bell replaces a Needs you page. New events ring it once (a short damped swing) and play a soft two-note chime if sound is on. Both can be switched off:

Usage limits

The top bar shows one chip per provider: its logo, two hairline meters (5-hour on top, weekly below) and the lower of the two numbers. Clicking opens the dropdown, which scales in from the chip. Each provider expands By model where the provider reports per-model limits. Meters turn amber under 25% and red under 5%. The text always says the number too, so colour is never the only signal.

Focused on one provider

Clicking a provider in the sidebar filters the board to it, and the top bar shows only that provider's two meters, plus a way back to everyone's usage.

Filters

Linear's pattern. Filter (or F) opens a list of categories; choosing one slides in its options with Select all and None; typing searches values across every category. Active filters sit under the top bar as chips you can remove. Clicking a provider in the sidebar is a shortcut for "Provider is X".

Chips read as sentences: Provider is any of Claude, Codex. "None" shows an honest empty result with a way out:

No chats match these filters

Projects

Every folder an agent has worked in. The list is Linear-style rows; a project page shows which providers know it, its chats, and what each provider can read from the folder. Providers that haven't worked in a project are shown, dashed, so the absence is clear rather than hidden.

Segmented control: the thumb slides on --duration-move.

Connections

One card per agent app. Every state has a dot and a word, never colour alone. The official installer and sign-in run behind the buttons; the step text crossfades as the install moves on, and a check pops once when it's done. Sign out asks first and says what stops working.

Not installed → Installing → Signed out → Waiting for sign-in → Connected

Onboarding and empty states

First run is full screen, centred, four counted steps after a welcome: Connect, Bring in your chats, Notifications, Ready. Steps slide 16px on a shared axis and Back slides the other way. Empty states say what belongs here and give the next action, never just "Nothing here".

Components

Buttons

One primary button per view. Every button dips to 97% on press. The Stop button swaps its label through a short blur. Icon-only buttons always have a label and a tooltip: the first tooltip waits, the next ones appear instantly.

Badges, state icons and logos

Feedback

Toasts rise from the bottom centre, pause while hovered or while the window is hidden, and leave faster than they arrive.

Motion

The board is used all day, so motion stays functional and quick. Things animate when they appear, travel or change state, never just to decorate. Exits are always faster than entrances. Keyboard-triggered actions open instantly in spirit, so nothing waits on an animation before you can type.

Reduced motion: travel, spin, sweep and scale are removed. Colour and opacity changes stay, because they still explain what happened.

Colour

Swatches read live from the tokens, so they follow light and dark.

Type

Geist for everything. Geist Mono only for file names and commands inside agent activity, never for UI labels. Numbers use tabular figures so meters and counts don't jitter.
